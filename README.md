# backyard-tub-planter
Specs and plans for the backyard bathtub planter.

## Tub Dimensions

- **Length:** 80"
- **Width:** 32"
- **Height:** ~16"

## April 30, 2026

I took some more measurements this evening to determine if a 2x4 can be positioned inside the permimeter of the tub (see diagram) without conflict with the tub itself... it can, nearly all the way around the 3 open sides of the tub.  In fact, the preliminary plan is to use a "C" shaped 2x4 frame with members laid down (so the 4" face on the ground), and another frame with members turned on their side (so the 2" faces facing up/down), and positioned 12" or so above the ground.  

Those frames should provide enough support to form a "C" shaped "wall" around the 3 open sides of the tub, formed using 16" lengths (or longer) of composite decking boards.
